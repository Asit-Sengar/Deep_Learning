# Perceptron

A focused study of the perceptron learning algorithm, one of the foundational models in machine learning and artificial neural networks.

## Overview

The perceptron is a simple linear binary classifier that learns a decision boundary by updating its weights when it makes mistakes. It is widely used to understand:

- supervised learning basics
- linear separability
- weight updates and optimization
- foundations of neural networks

## Objectives

- understand the perceptron update rule
- implement the algorithm from scratch
- test it on a simple labeled dataset
- observe how decision boundaries change during training

## File Structure

- `perceptron.ipynb` — implementation and experiments

## Typical Workflow

1. Load sample training data.
2. Initialize weights and bias.
3. Iterate through training samples.
4. Update weights for misclassified points.
5. Evaluate classification performance.

## Summary

This project is intended as a clean, beginner-friendly exploration of the perceptron algorithm and its core learning principles.
